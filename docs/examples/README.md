# Worked Examples

Grandmaster Mode is a practice, not a theory. These examples run real problems
through the four stages and end in a `🏁 Meta-Lesson`.

Each example is required to close the recursion: its meta-lesson must propose a
refinement to the method itself ([`grandmaster-mode.md`](../grandmaster-mode.md))
or to the repository. An example that only solves its case — without improving the
process that produced the solution — has added information *beside* the loop, not
*in* it (see the [thesis](../thesis.md) decision filter).

## Template

When adding an example, follow the four stages, then the output format, then a
meta-lesson that names a concrete change. Keep it short — the value is the
reasoning trace and the fed-back refinement, not length.
