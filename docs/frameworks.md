# Framework Areas

MindShift may use established lenses on learning, systems, and cognition, but no
lens is canonical. Frameworks are optional instruments for studying the canonical
research sequence:

```text
Observation → Pattern → Abstraction → Primitive → Transfer
```

A framework belongs here only when it helps an observed pattern become a
transferable abstraction or primitive that improves future modeling.

## Optional Lenses

- First Principles Thinking
- Pattern Recognition
- Learning Systems
- Meta-Learning
- Reflexive Intelligence
- Bateson Levels of Learning
- Dilts Logical Levels
- Cybernetics
- Kaizen / PDCA
- OODA Loops
- Systems Thinking
- Flow Theory
- Feedback Systems
- Cognitive Architecture
- Recursive Improvement

These lenses are vocabulary, not identity. Removing any one of them must not
change what MindShift is.
