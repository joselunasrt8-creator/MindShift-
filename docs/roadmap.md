# Roadmap — Future / Optional Work

This roadmap is intentionally small. Every item must pass the decision filter in
[`docs/thesis.md`](thesis.md):

> Does this strengthen the study of how observations become transferable
> abstractions that improve future modeling?

## In Scope

- Worked examples that demonstrate Observation → Pattern → Abstraction →
  Primitive → Transfer.
- Refinements that make the canonical research question clearer.
- Clarifications that remove ambiguity or unsupported claims.

## Out of Scope

- Runtime behavior.
- Infrastructure claims.
- Execution or agent capability.
- Authority, approval, legitimacy, execution eligibility, proof, governed
  mutation, replay, or reconciliation.
- Schemas, services, packages, or machine objects for primitives.
- Additional identity labels.
