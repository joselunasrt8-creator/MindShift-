# Authority Records

Authority is explicit maintainer approval.

Issues cannot authorize execution. Intent candidates are not authority. Authority
records must be manually created after review by an authorized maintainer.

An authority record must define:

- scope;
- constraints;
- expiry; and
- approved action.

Authority does not execute actions. It does not trigger, schedule, perform, or
complete work. It only records bounded approval that may be checked later by the
execution boundary checklist.

This directory is documentation only and remains non-operative.
