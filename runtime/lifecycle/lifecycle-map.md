# Lifecycle Map

```text
Issue
→ Intent Candidate
→ Manual Approval
→ Authority Record
→ Execution Boundary Checklist
→ Eligible / NULL
→ Separately Scoped Action
→ Proof Closure
→ Learning Log
→ New Observation
```

## Boundary Statements

- Issues do not authorize.
- Intent candidates do not execute.
- Authority does not execute.
- Eligibility is not proof.
- Proof does not authorize future actions.
- Learning does not mutate authority automatically.
- Learning does not mutate execution eligibility.
